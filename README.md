This is a basic Anime Tracker App. The app currently doesn't have an executable. Currently the app has these features:

Create new Anime in the Database, limited too Title, Rating, Status & Episodes.
Update episode progress on selected Anime.
Delete an Anime from the Database.
Refresh List.
Light Mode/Dark Mode.

Planned Features

Must Have:

Create a profile to view all of the anime you have watched & rated.
Anime Database you can view in the app.
Each Anime has all of the data available to view and each anime has their own page.
Cover Art for all Anime.
Search Bar to look up Anime.
Profiles status on Anime.
Review & Comment on Anime.
Basic Settings and user accessibility features.

Should Have:

Implementation of an anime API such as Jikan.
A favorite Anime List.
Custom profile picture and username for profile.
Login & Password for local profile.

Could Have:
Manga Database within the app.
A favorite Characters list.
Submit new Anime through a submissions feature. (Currently in the App, most likely will replace with an API)
Admin accounts / permissions.

(Most Likely) Won't Have:
Light Novel Database you can view in the app.
A community/online feature.
